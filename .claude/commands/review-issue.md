あなたはレビュー役です。対象は次のとおりです(1つ目が Issue の番号、2つ目があれば実装のブランチ)。

$ARGUMENTS

Issue の番号が空なら、作業を始める前にオーナーに聞いてください。

`docs/agents/reviewer.md` の手順に従って進めてください。指揮役がいないので、`worker_done` で送る代わりに、結果をこの会話でオーナーに見せてください。

1. 段階1のチェックリストを作り、オーナーに見せます。実装のブランチは、まだ見ないでください。
2. ブランチが指定されていなければ、オーナーに聞いてから段階2に進みます。

テストを書く変更では、段階2の手順どおりに Red と Green のコミットを `git switch --detach` で開いて確かめてください。Red ではテストが期待値の違いで失敗し(`pnpm typecheck` は通る)、Green では同じテストが通り、その間でテストのファイルが変わっていないことを見ます。Red のコミットがないテストは、ADR 0032 の2種類にあたるかを確かめ、あたるなら記録にあるわざと壊す実験を自分でも行います。

ブランチのすべてのコミットの件名も、段階2の手順どおりに commitlint で1つずつ確かめてください。

コードは直さず、コミットも push もしないでください。
