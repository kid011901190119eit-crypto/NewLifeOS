# 障害対応手順書(ランブック)

障害やアラートが発生したときに、何を確認し、どう対処するかを手順としてまとめます。焦っているときでも、上から順に実行すれば復旧できる状態を目指します。

## 書き方

アラート1種類につき1ファイルにします(例: `backup-failed.md`)。各ファイルには次を書きます。

1. **症状**: どんなアラート・状態か
2. **影響**: 何が使えなくなるか、データは無事か
3. **確認手順**: 原因を切り分けるために見る場所
4. **対処手順**: 復旧のための操作
5. **事後対応**: 再発防止のためにやること
