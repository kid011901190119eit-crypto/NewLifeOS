# 0003: 画面はReact SPA、APIはHonoで分離する

- ステータス: 承認
- 日付: 2026-11-04

## 背景
当初はNext.jsで画面とAPIをまとめて作る予定だった。しかし、APIをMCPサーバーやワーカーからも使う構成になり、役割をはっきり分けたほうがよくなった。

## 検討した選択肢
- **Next.js**: 画面とAPIを1つにまとめられる。サーバー側レンダリングが強みだが、個人用でSEOも不要なため、その利点はほとんどない。
- **React SPA + 独立したAPI(Hono)**: 画面は静的ファイルとして配信し、APIは別プロセスにする。役割分担が明確になる。

## 決定
画面はReact + ViteのSPA(PWA対応)、APIはHonoで別に立てる。APIはOpenAPI仕様書を自動生成し、そこから画面側の型付きクライアントを生成する。

## 結果
- APIを変更すると、画面側で型エラーとして気づける。
- 画面とAPIで別々のコンテナになり、デプロイの単位も分かれる。
