# 0004: 家計簿は複式簿記で記録する

- ステータス: 承認
- 日付: 2026-11-04

## 背景
現行の家計簿(Notion版)は、口座・口座間の移動・貸し借り・予定取引を扱っている。画面の使い勝手はそのままに、裏側のDBを作り込みたい。

## 検討した選択肢
- **単式(1取引1行)**: 現行と同じ形。単純だが、口座間の移動や貸し借りの扱いが場当たり的になる。
- **複式簿記(1取引に2行以上の仕訳)**: 会計ソフトの基本構造。お金の出どころと行き先を必ずペアで記録する。

## 決定
複式簿記で記録する。画面上は現行と同じ入力のまま、裏で仕訳に変換する。

## 結果
- 口座間の移動、貸し借り、開始残高を同じ仕組みで扱える。
- 貸し借りを相手ごとの勘定として持つため、未精算額を自動で計算できる。
- 「仕訳の合計は必ず0」というルールをDBの制約で守ることで、壊れたデータが入らなくなる。
- 金額は整数(円)で持ち、物理削除はしない。
