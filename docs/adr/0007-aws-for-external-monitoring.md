# 0007: AWSは外部死活監視にのみ使う

- ステータス: 承認
- 日付: 2026-11-04

## 背景
AWSを使ってみたいが、無料でメインサーバーを置き続けることはできない(ADR 0002)。一方で、サーバーが丸ごと止まった場合、サーバー自身は異常を通知できない。

## 決定
AWSの常時無料枠の範囲で、Lambda + EventBridge Schedulerによる外部からの死活監視を行う。GitHub ActionsからAWSへの認証はOIDCで行い、長期のアクセスキーは使わない。

## 結果
- 監視する側(AWS)と監視される側(Oracle)を別の事業者に置けるため、Oracleが丸ごと止まっても検知できる。
- 無料プランの期限(6か月)後も使い続けるには有料プランへの切り替えが必要。AWS Budgetsで課金が発生したら通知するよう設定する。
