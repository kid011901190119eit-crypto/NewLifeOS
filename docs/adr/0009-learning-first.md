# 0009: 主目的はオーナーの学習とし、理解を優先する

- ステータス: 承認
- 日付: 2026-11-04

## 背景
LifeOSは実用のためのアプリでもあるが、それ以上に、オーナーが現実の大規模Webアプリ開発を学ぶためのプロジェクトである。

## 決定
完成の速さより、オーナーが理解しながら進められることを優先する。

## 結果
- 個人アプリには不要な構成(監視、バックアップの自動復元テスト、IaC、署名付きイメージなど)も、学習のために意図的に入れる。
- AIエージェントは、作業を小さく分け、何をなぜ変えたかを説明し、新しい技術を導入するたびに `docs/learning/` に解説を書く。
- オーナーが説明できない巧妙な仕組みは入れない。
