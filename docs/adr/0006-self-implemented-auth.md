# 0006: 認証はID+パスワードとGoogle OAuthを自前実装する

- ステータス: 承認
- 日付: 2026-11-04

## 背景
利用者は自分1人だけだが、インターネットに公開するため認証は必須。認証の仕組みを学ぶことも目的の1つ。

## 検討した選択肢
- **パスキー**: 安全で実装も比較的シンプル。ただし、学びたいOAuthやパスワード管理の要素が少ない。
- **認証サービス(外部SaaS)に任せる**: 安全で楽だが、中身を学べない。
- **ID+パスワードとGoogle OAuthを自前で実装する**: 手間はかかるが、認証の仕組みを一通り学べる。

## 決定
ID+パスワード(+TOTPによる2要素認証)とGoogleログインを自前で実装する。ただし、ハッシュ化やJWTなどの暗号処理は、実績のあるライブラリを使う。

## 結果
- パスワードはArgon2idでハッシュ化し、流出済みパスワードのチェック、レート制限、一時ロックを入れる。
- 新規登録は無効にし、オーナーのアカウントのみ存在させる。
- 自前実装の分、テストとレビューを厚くする必要がある。
