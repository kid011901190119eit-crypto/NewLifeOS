# 0005: エージェント連携はMCPコネクタ方式にする

- ステータス: 承認
- 日付: 2026-11-04

## 背景
AIエージェントから自然文でLifeOSを操作したい。ただし、Claude Pro(既存の契約)以外には費用をかけたくない。将来、別のエージェントに乗り換える可能性もある。

## 検討した選択肢
- **Claude APIをLifeOSのサーバーから呼ぶ**: 画面内にチャットを作れるが、API料金が従量課金でかかる。
- **Claude Agent SDKをProのログインで使う**: 現時点では利用枠の範囲で使えるが、2026年に規約が何度も変わっており、安定しない。
- **LifeOSをリモートMCPサーバーにし、Claudeアプリのカスタムコネクタとして接続する**: Proの契約内で使える。MCPはオープン標準なので、他のエージェントにも接続できる。

## 決定
LifeOSをリモートMCPサーバーとして作り、Claudeアプリから接続する。MCPサーバーはOAuth 2.1の認可サーバーも兼ねる。

## 結果
- 追加費用なしでエージェントから操作できる。
- エージェントとの会話はClaudeアプリ側で行い、LifeOSの画面内にはチャット欄を置かない(MVPの範囲外)。
- MCPサーバーはインターネットに公開する必要があるため、認証を厳重にする。
