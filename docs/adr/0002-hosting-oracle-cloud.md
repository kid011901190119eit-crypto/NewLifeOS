# 0002: ホスティングはOracle Cloud Always Freeにする

- ステータス: 承認
- 日付: 2026-11-04

## 背景
当初はVercelでホスティングする予定だった。しかし、常駐するワーカーや定期実行、10個以上のコンテナを動かす構成になったため、Vercel単体では対応できなくなった。また、費用は0円に抑えたい。

## 検討した選択肢
- **Vercel**: 手軽だが、常駐プロセスやDB、監視スタックを置けない。
- **AWS**: 使ってみたかったが、2025年7月以降の無料プランは6か月またはクレジット消化で終了し、常時稼働のサーバーを無料で置き続けられない。
- **自宅サーバー**: 月額はほぼ0円だが、ハードウェアの用意が必要。
- **Oracle Cloud Always Free**: ARMの仮想マシン(2 OCPU・12GB)を期限なしで無料で使える。

## 決定
Oracle Cloud Always FreeのARM仮想マシン上で、Docker Composeで運用する。

## 結果
- すべてのイメージをARM64でビルドする必要がある。
- 30日以上アイドル状態が続くとアカウントが停止の対象になるため、常時稼働させておく。
- 作成時に容量不足エラーが出ることがある。ホームリージョンは後から変更できないため、慎重に選ぶ。
